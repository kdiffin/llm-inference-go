# Manual browser checks

- Select every output cell; step to completion; compare to a hand dot product. Back/reset and play/pause work.
- Change all three dimensions; the shared dimensions match and selection resets.
- Focus or hover a memory cell; grid and strip highlight the same element. Change byte size; index stays fixed and offset changes.
- Enter a prediction; explanation stays hidden until submission. Reload; it persists.
- Enter notes and actual benchmark lines with ns/op; repeated lines yield separate bars. Text without benchmark lines produces no chart.
- Export; modify a note; import the backup and confirm replacement. Invalid JSON must preserve current notes.
- Complete requires prediction, understanding confirmation, test confirmation, measurements, observations, reflection.
- Keyboard navigation reaches matrix output and memory cells, form fields, details, navigation and controls.
- At 375px and desktop widths check reading order, wrapping and usable diagram controls.
- With reduced motion enabled the lesson does not autoplay; playback is explicit.
- Deny browser storage: notes show an export warning rather than crashing.
